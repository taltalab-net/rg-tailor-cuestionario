# RG Tailor · Cuestionario de Serafín

Página estática de Taltalab para que Serafín responda hablando o escribiendo: a quién quiere vestir, para rehacer su LinkedIn, y su historia, para terminar la web.

Graba la voz en la propia página y la guarda en el navegador. No hay servidor: nada sale del dispositivo hasta que la persona lo envía. Funciona en Google Chrome; en Safari no.
